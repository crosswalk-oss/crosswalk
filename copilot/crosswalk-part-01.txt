# Agent rules

Rules for any person or AI agent changing Crosswalk. Transcribed from the project owner's rules file; where the
original line was cut off, the end is marked _[…]_ and should be replaced with the original wording.

---

## 1. Data: fictional only, no exceptions
1. Use only the fictional "Arroyo Valley Gas" data in `src/core/seed/` or data the agent generates.
2. Never accept, request, read, or paste:
   - Utility company project data, estimates, TICs, BOEs, actuals, SAP or Unifier exports, or screenshots
   - Anything marked Confidential or Restricted, or covered by PU Code §583
   - Real cost-element, vendor, or cost-center mapping tables
   - Org charts, employee names, or emails
   - Customer data or personal information of any kind
3. **Scrub real identifiers.** Replace real-looking pipeline line numbers in the seed (e.g. Line 85, 1004, 2001, 3000) with obviously fake ones _[…]_ — no street pairings with real line numbers.
4. **No real vendor names.** Use fakes (e.g. "Delta Pipeline Co."). No real contractors, consultants, or staffing firms.
5. **No real people.** User names in the demo must be fictional.
6. If the human pastes something that looks like real company data, **stop, refuse to use it, and ask them to remove it** from the session _[…]_

## 2. Third-party IP
7. Do not reproduce, copy, or reverse-engineer Oracle Unifier, Primavera P6, HCSS HeavyBid, or Enstoa/Concertus code, screens, adapters, or docs. Use public standards (AACE, GAO) and the requirements in this repo.
8. Use only dependencies with permissive open-source licenses (MIT, Apache-2.0, BSD, ISC). Run a license check before adding one. No GPL or AGPL _[…]_
9. Do not copy code from sources of unknown license.

## 3. No AI or outside calls in the running app
10. Ship the app with all AI features **off by default** (`src/core/ai.ts`). No calls to any LLM API in the demo build.
11. The app makes no network calls except to its own API. No telemetry, analytics, CDN fonts, or third-party scripts.
12. No secrets in code. Configuration goes in environment variables; `.env` files go in `.gitignore`.

## 4. Fairness in the estimating model
13. Factors must be physical, legal, or logistical cost drivers (soil, permits, HCA, remoteness, traffic, work-hour restrictions).
14. **Never** use demographic or wealth attributes as model inputs: `location.dac`, income, race or ethnicity, home value, or zip-code proxies. A test fails if any factor binds to `location.dac`.
15. Every estimate must show its drivers itemized (no black box).

## 5. Architecture: portable to AWS serverless
16. Keep the engine pure: `src/core/engine` has no imports from UI, storage, network, or framework code.
17. All persistence goes through one data-access interface, with two implementations: the browser (localStorage) version for the demo, and a Postgres version for later. Nothing outside the interface touches storage.
18. API handlers are plain `(request) => response` functions, so they run on Vercel functions now and AWS Lambda later. No framework-specific server features.
19. Postgres only through plain SQL migrations. If Supabase is used, use it **as Postgres only**: no Supabase Auth, row-level-security policies, edge functions, or realtime.
20. Login through a swappable OIDC interface that uses only the user's ID, name, and group claims. Groups map to Crosswalk roles.
21. The audit log is append-only (no update or delete) in every storage implementation.
22. Infrastructure goes in Terraform. No click-built cloud resources.
23. No containers or VMs. Static front end plus serverless functions only.

## 6. Quality bar: every change
24. Run `npm run typecheck` and `npm test` before calling a change done, and report the results. Never mark failing work complete.
25. Every engine change ships with vitest tests.
26. Small commits with plain-English messages, one feature per branch, and a pull request describing what changed and how it was tested.
27. Don't break the demo. `npm run build` must still produce the single-file HTML.
28. Mark anything AI-generated that a human must verify (formulas, regulatory text, BOE wording) with `// VERIFY:` and list those items in the PR.

## 7. Scope: the usable demo (in this order)
1. Scrub the seed data (rules 3–5) and add the `location.dac` guard test (rule 14).
2. Apply `crosswalk-factor-model.patch`. Typecheck and test.
3. Factor model admin screen (weights, backtest, override reasons, publish gate, version history).
4. Quick estimate screen showing the factor-model path: drivers, range, BOE text, rate-table comparison, estimator adjustment.
5. Monte Carlo view using the model's base uncertainty.
6. SAP CSV import against a **fictional** CSV in the same column layout, plus a reconciliation view.
7. Data-access interface (rule 17) with the browser version only. Postgres comes after approvals.

**Done =** a stranger can open the built HTML or the Vercel URL, run a Class 5 estimate, adjust the model in admin, and see the backtest. All data is fictional, and all tests pass.

## 8. Hosting the demo
- Public hosting (Vercel) is for **fictional data only**, with no company branding, logos, or names.
- No company login, no company email sign-up, no uploads of real files.
- Hosting with real data happens only inside the company's managed cloud after architecture review approval.

# Contributing to Crosswalk

Thanks for helping. Read [AGENT_RULES.md](AGENT_RULES.md) first. It binds people and AI agents alike.

- **Fictional data only.** Use the Arroyo Valley Gas seed or data you generate. Never commit a real
  utility's projects, estimates, actuals, exports, mapping tables, people, vendors or screenshots.
- **No proprietary vendor code or screens.** Use public standards (AACE, GAO) instead.
- **No new dependency** unless it is MIT, Apache-2.0, BSD or ISC. Run `npm run licenses` after adding one.
- **No outside calls** from the running app (no CDNs, fonts, telemetry or analytics). AI assist stays off by
  default.
- **Fair estimating.** Factors are physical, legal or logistical drivers only, never demographic or wealth
  attributes.

## Workflow

1. One feature per branch, small commits with plain-English messages.
2. Before opening a pull request, run all of these and paste the results into the PR:
   - `npm run typecheck`
   - `npm test`
   - `npm run build` (it must still produce the single self-contained `dist/index.html`)
3. Every engine change ships with vitest tests next to the code (`*.test.ts`). `buildSeed()` from
   `@/core/seed` gives you the full demo dataset.
4. Mark anything a human must check (formulas, regulatory text, BOE wording) with `// VERIFY:` and list
   those lines in the PR.
5. Keep `src/core/engine` pure: it imports only `../types`, `../util` and sibling engine files. All storage
   goes through `src/core/data`. `src/agent-rules.test.ts` enforces both.

Imports use the `@/` alias for `src/`.

## Data and mutations

- Types: `src/core/types.ts` (read it first — every record shape is there).
- Read: `const s = useStore()` (whole state) or `useStore(s => s.projects)`. Helpers: `useMe()`,
  `personName(s, id)`, `categoryName(s, id)`.
- Write: `mutate(d => { ...mutate the immer draft... }, { entity, entityId, action, summary, projectId })`.
  The second arg appends an audit entry — include it for every user action that changes data.
- New ids: `uid('prefix')`. "Today" is `s.settings.asOf` (the demo clock, 2026-10-28). Timestamps: `nowISO()`.
- Records are immutable once approved: create a new version instead of editing an approved estimate,
  snapshot, gate decision or workflow history.

  `parametricLines`, `ratesFor`, `approveEstimate`, `createBudgetFromEstimate`, `benchmark`, `estimateBridge`,
  category ids `LOADER_CAT`, `ESC_CAT`, `CONT_CAT`.
- `engine/position.ts`: `position(s,pid)` → budget/EAC/actual/contingency/exposure; `activeBudget`;
  `takeSnapshot(d,pid,type,label,opts)`; `snapshotsFor`; `latestOf`; `compareSnapshots(a,b)`;
  `thresholdBreaches(s,p)`; `nextMilestone`.
- `engine/risk.ts`: `riskScore`, `riskBand`, `pert`, `expectedCost`, `exposure`, `isActive`, `monteCarlo`,
  `LIKELIHOOD_LABELS`, `CONSEQUENCE_LABELS`.
- `engine/evm.ts`: `evmSeries(periods)`, `evmMetrics(periods, bac)`.
- `engine/workflow.ts`: `startWorkflow(d, key, {title, recordType, recordId, projectId, data})` — pass
  `data.amount` for anything routed by dollar authority; `actOnWorkflow`, `recallWorkflow`, `tasksFor`,
  `simulate`, `resolveAssignees`, `laneOf`, `latestDef`, `doaRoleFor`. Starting a workflow sets the
  record's status (estimate → in-review, etc.) and completion applies the outcome (see `onComplete`).

  Forecast record: `spread[fnId][YYYY-MM]` = ETC; `contingencyHeld`; `actualsThrough`; `status` draft/submitted/approved/returned;
  process key `forecast-review` (recordType 'forecast'; completion sets status and locks it). CostPeriod.byFunction = actuals split.

## Forecast line items, SAP actuals, profiles (engine/lines.ts, engine/sap.ts)

- `s.settings.forecastLines` — line items (code '06.10'), each rolls up to ONE WBS function (`functionId`)
  and owns CBS categories (`categoryIds`). `forecastLines(s)`, `linesOfFunction(s, fnId)`, `lineById`.
- Budget/actuals by line: `budgetByLine(s, pid)` → `{byLine, contingency}`, `actualsByLine(s, pid)`,
  `actualsByLineMonth(s, pid)` (Grid = key → 'YYYY-MM' → $). `linesToFunctions(s, byLine)`, `rollupGrid(s, lineGrid)`.
- Forecast: `f.lineSpread` (line × month ETC) is authoritative; `f.spread` is its roll-up by function. After
  editing `lineSpread` inside `mutate`, call `syncForecast(d, f)` (re-derives spread, eac, byYear).
  `lineGridOf(s, p, f)` reads any version at line level (old versions only had `spread`).
- Profiles per WBS function: `f.profiles[fnId] = {profileId, start, end, adjusted, appliedAt}`. Built-in ids
  are the SPREAD_METHODS ('even','scurve','front','back','bell'); custom ones live in
  `s.settings.spreadProfiles` (weights resampled to the window, optional `zeroMonths` black-outs).
  `applyProfile(s, p, f, fnId, {profileId,start,end}, fnTotal?)` → new line grid for that function's lines.
  After a profile is applied, cells stay editable; any hand edit sets `profiles[fnId].adjusted = true`.
  `allProfiles(s)`, `profileName(s, id)`, `profileWeights`, `spreadByWeights`, `splitExact`, `allocate`.
- ETC/EAC by function: `etcEacByFunction(s, p, f)` → `{rows: FunctionRow[] (with nested `lines: LineRow[]`),
  contingencyHeld, totals}`; each row has budget, actual, etc, eac, vac (= budget − EAC), pctSpent, profile.
- SAP: `s.settings.sapMappings` (priority-ordered rules: cost-element range, optional `wbsSuffix`,
  optional `textContains`, target 'line' | 'allocate' (loader settlements spread pro-rata) | 'exclude').
  `parseSapExtract(text, fallbackPeriod)` → rows/errors/columns; `stageImport(d, rows, fileName)`;
  `remap(d, importId)` after rules change; `resolveTxn(d, txnId, {lineId|exclude|projectId}, note)`;
  `postImport(d, importId)` → `{ok, reason}` (unmapped / no-project rows block posting; posting rebuilds
  CostPeriod.actual/byLine/byFunction for each project-period in the file, replacing earlier SAP data);
  `discardImport`; `matchRule(rules, row)`; `projectForWbs(s, wbs)`; `txnsFor(s, pid, {lineId, fnId, period})`
  for drill-down; `sampleExtract(s, period)` builds a demo CSV. Collections: `s.actualsImports`, `s.actualTxns`.
  Seed: P07–P09 posted; `CJI3_FY2026_P10_wk4.csv` staged with 4 exceptions (unknown cost element 5450110,
  WBS C.PSE.9999 with no project, a credit memo, a balance-sheet transfer that the exclude rule catches).
  `periodLines(s, rows)` is the posting roll-up (allocation + whole-dollar rounding) shared with reconciliation.
- Fictional sample: `samples/sap-actuals-fictional.csv` (CJI3-style headers, built by `fictionalSapExtract` in
  engine/sapSample.ts from the seed's posted P09 rows for six projects plus quirks; regenerate with
  `npm run sample:sap`). The SAP actuals page bundles it via `?raw` ("Load the fictional sample file"). Only
  fictional data may be loaded in the public demo.
- Reconciliation (engine/reconcile.ts): `reconcile(s, rows, {period})` compares SAP project cost (rows through the
  current mapping table, less rule exclusions; no-project rows bucketed) with posted `CostPeriod.actual/byLine/
  byFunction` and the latest forecast's actual months, per project-period → status ties | lines-differ | differs |
  not-posted (`RECON_TOLERANCE` $1). Rows are matched to posted transactions by period, WBS, document, cost element
  and amount; `items` (sap-only, crosswalk-only, mapped-differently) carry each row's effect so differences are
  explained. `reconCsvRows` / `reconItemCsvRows` for export. UI: Reconciliation tab on SAP actuals;
  `openReconciliation({projectId})` is the per-project entry (forecast tab footer).

## Class 5 quick estimate (engine/quick.ts)

- `s.historicalCosts`: direct $/unit (P10/P50/P90, n, baseYear, category `mix`) by asset type × work method ×
  diameter band × terrain ('any' allowed). Units: ft, site, hp, station. `QUICK_CATALOG` lists asset types,
  their work methods, unit and whether diameter bands apply. `DIAMETER_BANDS`, `bandOf(dia)`, `UNIT_LABEL`.
- `findHistorical(s, inputs)` → `{row, match: 'exact'|'any-terrain'|'nearest-band'|'none'}`;
  `computeQuick(s, inputs, basis='p50', adjustPct=0)` → direct, loaders, contingency, total, low (P10), high (P90),
  regionFactor (settings.quickEstimate.regionFactors), escalationFactor (base year → midpoint year).
  `inputsFromProject(s, p)` pre-fills. `createQuickEstimate(d, pid, inputs, requestNote, byId?, needBy?)` makes
  an Estimate with `method: 'quick'`, `cls: 5`, `quick: {…}` and lines from the mix. Route it with
  `startWorkflow(d, 'class5-review', {title, recordType: 'estimate', recordId: e.id, projectId, data: {amount, note}, startedById})`
  then `actOnWorkflow` on the 'prep' step to submit. Steps: prep (requester) → est (role estimator, any) → lock.
  On approval the completion hook approves the estimate. `adjustQuickEstimate(d, id, {pct, basis?, reason})`
  is how an estimator adjusts during review (keeps before/after + audit). `deriveFromClosed(s, p)`.

## Finance, estimating administration and messaging (see types.ts)

- Regions are North / West / South / East (`project.location.district`). Counties: `project.counties` [{county, pct}].
- `s.settings.estimating` (EstimatingConfig): regions, regionFactors, contingencyByClass, taxRates (county %), taxableCategoryIds,
  units (allowed units), quantityTypes (allowed scope quantities; `feeds` says which estimate input it drives), scopeLibrary
  (in/out-of-scope + assumptions picklists), maturityItems (class checklist, maintained by estimating), rateTableVersion + history.
  `UnitCostRate.region` = region-specific rate row. `EstimateLine.override` = estimator override of a locked unit cost.
  Loaders (`settings.loaderRates`) and escalation (`settings.escalationByYear`) are portfolio-wide and locked per project.
- `project.scope.capitalPct` (rest is O&M); `scope.quantities[].typeId` → quantityTypes.
- `project.finance` = { woa, ios: InternalOrder[] } (IO type capital|om, status, functionIds). Key facts display; Finance tab manages.
- Commitments = `s.contracts` (call-offs): poNumber, poTotal (blanket PO), pctOfPo, scope, lineIds (forecast lines), ioId.
  `s.commitmentChanges` = RFI / contract change orders, the single entry point for commitment changes; workflow key
  'commitment-change' (prep PM → CM → project controls → DOA approval); approval adds `amount` to `contract.changeOrders`.
  `Change.contractIds` (commitments a project change affects), `Change.scheduleNotice` (task to the scheduler; P6 is not written back).
- Messaging: `s.channels` (project | direct) and `s.messages`. Notifications have `kind`.
- `settings.workflow` { reminderDays, escalateAfterDays }; `Person.outOfOffice` { from, to, delegateId } (engine already routes to delegate).
- `settings.features` { fieldTailboard, portfolioPlanning, opQual } — phase-2 modules, off by default.
- WBS: contingency is 990 (held separately), undifferentiated 999.

- Kit: `src/ui/kit.tsx` — Button, Badge, StatusBadge/statusTone, HealthDot, ClassBadge, Avatar, Progress,
  StageTrack, PageHeader, Panel, Stat, KV, Empty, Callout, Tabs, Table (sortable columns), Field, Input,
  TextArea, Select, Checkbox, MoneyInput, Modal, Drawer, ConfirmButton, SegButtons, Mono, Section, AiTag.
- Charts: `src/ui/charts.tsx` — LineChart, BarChart, HBarChart, Waterfall, Sparkline, Histogram, RiskMatrix, RangeBar.
- `toast('Saved')` from `src/ui/toast.tsx` after every action. `Icon` from `src/ui/icons.tsx`.
- Shared: `<WorkflowStatus instanceId=… />` (history + approve/return/reject for the current user),
  pickers `PersonSelect`, `ProjectSelect`, `ProgramSelect`, `ProgramTag` in `src/views/shared/pickers.tsx`.
- Routing: hash links only. `projectHref(id, tab)` → `#p-1042-estimates`; tabs: overview, info, map, lifecycle,
  estimates, baselines, cost, forecast, changes, risk, safety, permits, records, evidence, activity.
  Top-level: `#portfolio #projects #new-project #inbox #gates #estimating #risk #safety #field
  #regulatory #planning #workflows #wf-<key> #admin #audit`. Use `<a href>`; `go(hash)` in handlers.
- Styling: Tailwind with token colors only — `bg-surface bg-sunken bg-ground border-line text-ink
  text-muted text-faint text-good text-warn text-bad text-info text-link bg-marker text-markerink bg-steel`.
  Opacity works (`bg-bad/10`). NEVER hard-code hex/rgb or use `dark:` variants (tokens handle dark mode).
  Fonts: `font-display` (headings), default body, `font-mono` for IDs/codes. `tabular-nums` for figures.
  Amber `marker` = "needs action" only. Semantic good/warn/bad for status.
- Treatment: a dense, polished professional tool (think a modern capital-project platform). Summary before detail,
  real typographic hierarchy, tables over cards, state shown as badges/dots. No emoji. No lorem ipsum.
  Write copy from the user's side ("Submit for approval", toast "Submitted for approval").
- Must work at phone width (~400px): grids collapse (`grid-cols-1 md:grid-cols-2`), tables scroll inside
  their own container (Table already does), give text containers `min-w-0`.
- The page may run in a sandboxed frame: don't use `alert/confirm/prompt` (use ConfirmButton / Modal);
  download with `saveFile(filename, data, mime)` from `@/core/download` (plus `toCSV`, `htmlDoc`);
  no window.print; no external fetches.
- AI assist is OPTIONAL and OFF by default (Configuration → AI assist points it at the organization's LLM
  gateway). `ask(prompt)`, `askJSON<T>(prompt)` from `@/core/ai`; call only from a click; `useAiAvailable()`
  is false by default → render NO AI controls and no "AI unavailable" notes. Never name a vendor or model
  in UI copy; say "AI assist". New features must not depend on AI.

## Quality bar

Every view opens in a realistic working state from the seed data, every button does something real
(mutates the store, starts a workflow, downloads a file, or opens a drawer), and every number traces to
records. Build complete features, not placeholders.

===== FILE: README.md =====
# Crosswalk

Open-source capital project delivery for gas utilities. It covers:

- stage gates
- AACE-class estimating that becomes the budget
- a transparent Class 5 factor model with a backtest
- forecasting by WBS function
- SAP actuals import and reconciliation
- risk-linked contingency, change control and job safety plans
- a workflow designer that also prints the SOP

Every dollar, date and scope change traces back to an approved decision and its evidence.

**Live demo: [crosswalk-demo.pages.dev](https://crosswalk-demo.pages.dev)**, with a shared database. It redeploys on every push to `main`.

> **All data in this repository is fictional.** The demo runs a made-up utility, **Arroyo Valley Gas**:
> 30 projects on five programs, with lines named AV-11 to AV-28 and vendors such as "Delta Pipeline Co.".
> No real company's projects, costs, people, vendors or systems are included, and none may be added.
> See [AGENT_RULES.md](AGENT_RULES.md).

## Try it

- **Hosted demo:** everyone shares one dataset in a Postgres database. Anyone with the link can look around;
  changes need the edit passcode and are saved for everyone, with every change kept in the database's history.
- **Offline copy:** download [`Crosswalk.html`](Crosswalk.html) and double-click it. It is the whole app in one
  file and makes no network calls. It isn't connected to the database, so changes there are not saved.
- **Run locally with the database:**

  ```bash
  npm install
  npm run build && npm run serve:local   # http://localhost:8788, edit passcode "local", in-memory Postgres
  npm run dev                            # UI only, hot reload, not saved
  ```

### A five-minute demo path

1. **Estimating → Quick estimate.** Pick a project, or enter pipe size, length, soil, permits, traffic and
   work hours. The factor model returns:
   - a Class 5 cost
   - every driver's effect, itemized
   - a P10–P90 range
   - a comparison with the rate-table estimate
   - draft basis-of-estimate (BOE) text

   Apply an estimator adjustment with a reason and send it for review.
2. **Estimating → Admin → Factor model.** Change a weight or a multiplier and watch the backtest against
   60 fictional closed projects update (MAPE, bias, P10–P90 coverage). Publishing a new version goes
   through an approval gate, and every version is kept.
3. **Monte Carlo.** Run the model's base uncertainty plus project risks to get P10/P50/P80/P90.
4. **SAP actuals.** Click **Load the fictional sample file**. It is a CJI3-style extract in
   `samples/sap-actuals-fictional.csv`. Map it, post it, then open **Reconciliation** to see SAP tie to
   posted actuals and the forecast by project, period, line and cost element.
5. **Any project.** Look at its gate readiness, baselines, forecast by function, change requests, risk
   register and audit trail.

## Host the public demo (free)

The demo runs on **Cloudflare Pages** (the page plus `/api` functions, free and commercial use allowed) with
**Neon** Postgres (free tier). `.github/workflows/deploy.yml` does everything on each push to `main`: typecheck,
tests, license check, build, SQL migrations, then deploy. It needs four repository secrets:

| Secret | Where it comes from |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | Cloudflare → My Profile → API Tokens → a token with **Cloudflare Pages: Edit** |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare dashboard → the account ID on the right |
| `DATABASE_URL` | Neon → your project → Connection string |
| `EDIT_PASSCODE` | Any phrase you choose; people type it to edit |

Without the secrets the workflow only runs the checks. How the data is stored:

- A "generation" starts from a full snapshot.
- Every edit is appended as an ordered change (immer patches).
- Database triggers refuse any update or delete (`migrations/001_shared_state.sql`).
- "Reset demo data" starts a new generation. Nothing is ever deleted.
- Secret settings (AI key, map tokens) and the persona you act as never leave the browser.
- On the shared demo, file uploads and pasted extracts are turned off. Only the bundled fictional samples load.

The public demo is for fictional data only:

- no company branding
- no company login or email sign-up
- no uploads of real files

Hosting real data belongs inside an organization's managed cloud, after its architecture review.

## Architecture

```
src/core/types.ts          domain model (read it first)
src/core/engine/*.ts       pure functions, no UI/storage/network imports; every change ships with vitest tests
src/core/seed/             fictional reference data + history replayed through the engine
src/core/data/             the one data-access interface: the app's own API (Postgres); UI preferences stay in the browser
src/core/sync.ts           loads the shared data, sends each change, merges others' edits, re-applies on conflicts
src/server/                the API: plain (request) => response handler, SQL repository, migration runner
functions/api/             Cloudflare Pages adapter for the API handler
migrations/                plain SQL migrations (append-only tables)
src/core/auth/             swappable OIDC-style interface: id, name, groups → Crosswalk roles
src/core/store.ts          zustand + immer; every write goes through update(fn, audit); the audit log is append-only
src/views/                 one folder per module
samples/                   fictional sample files (SAP extract)
```

The planned production path (see [AGENT_RULES.md](AGENT_RULES.md) §5):

- a static front end plus serverless `(request) => response` handlers (Cloudflare Pages functions now, AWS Lambda later)
- Postgres through plain SQL migrations
- OIDC sign-in
- infrastructure in Terraform (today the deploy is scripted in GitHub Actions; Terraform is still to do)
- no containers or VMs

// Turn Vite's single-file build into artifact page content (no doctype/html/head/body wrappers).
import fs from 'node:fs'
const src = fs.readFileSync('dist/index.html', 'utf8')
const bodyOpen = src.lastIndexOf('<body>')
const bodyClose = src.lastIndexOf('</body>')
const headOpen = src.indexOf('<head>')
const headClose = src.lastIndexOf('</head>', bodyOpen)
const head = src.slice(headOpen + 6, headClose)
const body = src.slice(bodyOpen + 6, bodyClose)
let keep = head.replace(/<meta charset[^>]*>/i, '').replace(/<meta name="viewport"[^>]*>/i, '')
const title = keep.match(/<title>[^<]*<\/title>/)[0]
keep = keep.replace(title, '')
const out = `${title}\n${keep.trim()}\n${body.trim()}\n`
fs.mkdirSync('artifact', { recursive: true })

/**
 * The audit log is append-only (rule 21): an update may add entries but never change or remove existing ones.
 * Violations are rejected and the update is discarded.
 */
export function auditIntact(before: AppState['audit'], after: AppState['audit']): boolean {
  if (after.length < before.length) return false
  for (let i = 0; i < before.length; i++) if (after[i] !== before[i]) return false
  return true
}

interface Store extends AppState {
  sync: SyncStatus
  /** The ONE way to change data. `fn` mutates an immer draft. Optional audit entry is appended. */
  update: (fn: (d: AppState) => void, audit?: AuditInput, opts?: UpdateOptions) => void
  reset: () => void
  setUser: (id: string) => void
}

export const strip = (s: Store | AppState): AppState => {
  const { update, reset, setUser, sync, ...rest } = s as Store
  void update; void reset; void setUser; void sync
  return rest
}

export const useStore = create<Store>()((set, get) => ({
  ...buildSeed(),
  sync: INITIAL_SYNC,
  update: (fn, audit, opts) => {
    const prev = strip(get())
    const [next, patches, inverse] = produceWithPatches(prev, (d: AppState) => applyChange(d, fn, audit))
    if (!auditIntact(prev.audit, next.audit)) {
      console.error('Rejected an update that changed or removed audit log entries (the audit log is append-only).')
      return
    }
    if (!patches.length) return
    set(next)
    changeListener?.({ fn, audit, background: !!opts?.background, patches, inverse })
  },

    if (resetHandler) return resetHandler()
    const me = get().currentUserId
    const s = buildSeed()
    if (s.people.some((p) => p.id === me)) s.currentUserId = me
    set(s)
  },
  setUser: (id) => {
    prefs.setRaw(USER_KEY, id)
    get().update((d) => { d.currentUserId = id })
  },
}))

export function evalCondition(c: Condition | undefined, obj: unknown): boolean {
  if (!c) return true
  const v = get(obj, c.field) as any
  const t = c.value as any
  switch (c.op) {
    case 'eq': return v === t
    case 'ne': return v !== t
    case 'gt': return Number(v) > Number(t)
    case 'gte': return Number(v) >= Number(t)
    case 'lt': return Number(v) < Number(t)
    case 'lte': return Number(v) <= Number(t)
    case 'in': return Array.isArray(t) && t.includes(v)
    case 'truthy': return !!v
    case 'falsy': return !v
  }
}
export function describeCondition(c?: Condition): string {
  if (!c) return 'Always'
  const ops: Record<string, string> = { eq: 'is', ne: 'is not', gt: '>', gte: '≥', lt: '<', lte: '≤', in: 'is one of', truthy: 'is yes', falsy: 'is no' }
  const val = c.op === 'truthy' || c.op === 'falsy' ? '' : ' ' + (Array.isArray(c.value) ? (c.value as unknown[]).join(', ') : String(c.value))
  return `${c.field} ${ops[c.op]}${val}`
}

/** Deterministic PRNG (mulberry32) for seed data and Monte Carlo reproducibility. */
export function rng(seed: number) {
  let a = seed >>> 0
  const next = () => {
    a |= 0; a = (a + 0x6d2b79f5) | 0
    let t = Math.imul(a ^ (a >>> 15), 1 | a)
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
  return {
    next,
    int: (lo: number, hi: number) => Math.floor(lo + next() * (hi - lo + 1)),
    pick: <T,>(xs: readonly T[]): T => xs[Math.floor(next() * xs.length)],
    chance: (p: number) => next() < p,
    range: (lo: number, hi: number) => lo + next() * (hi - lo),
  }
}

/** Sample a triangular distribution. */
export function triangular(u: number, min: number, ml: number, max: number): number {
  if (max <= min) return ml
  const f = (ml - min) / (max - min)
  return u < f ? min + Math.sqrt(u * (max - min) * (ml - min)) : max - Math.sqrt((1 - u) * (max - min) * (max - ml))
}

export const lineTotal = (l: EstimateLine) => Math.round(l.qty * l.unitCost)

export const LOADER_CAT = 'cat-loaders'
export const ESC_CAT = 'cat-escalation'

export interface EstimateTotals {
  lines: Money // direct cost before sales tax
  direct: Record<string, Money> // line totals by category, before sales tax
  byCategory: Record<string, Money> // lines (taxable categories incl. their sales tax) by category + loaders + escalation (excludes contingency)
  tax: Money // sales tax on taxable categories (county split stamped on the estimate)
  loaders: Money
  escalation: Money
  base: Money // lines + loaders + escalation
  contingency: Money
  total: Money // base + contingency
  low: Money
  high: Money
}

export function estimateTotals(e: Pick<Estimate, 'lines' | 'loaders' | 'escalationPct' | 'contingency' | 'cls'> & { salesTax?: Estimate['salesTax'] }): EstimateTotals {
  const direct: Record<string, Money> = {}
  for (const l of e.lines) direct[l.categoryId] = (direct[l.categoryId] || 0) + lineTotal(l)
  const lines = sum(Object.values(direct))
  const byCategory: Record<string, Money> = { ...direct }
  let tax = 0
  if (e.salesTax && e.salesTax.pct > 0) {
    for (const c of e.salesTax.categoryIds) {
      if (!direct[c]) continue
      const t = Math.round(direct[c] * e.salesTax.pct / 100)
      byCategory[c] += t
      tax += t
    }
  }
  const loaders = Math.round(lines * sum(e.loaders.map((x) => x.pct)) / 100)
  // VERIFY: escalation applies to lines + tax + loaders; contingency applies to that base (lines + tax + loaders + escalation).
  const escalation = Math.round((lines + tax + loaders) * e.escalationPct / 100)
  if (loaders) byCategory[LOADER_CAT] = loaders
  if (escalation) byCategory[ESC_CAT] = escalation
  const base = lines + tax + loaders + escalation
  const contingency = Math.round(base * e.contingency.pct / 100)
  const total = base + contingency
  const r = CLASS_RANGES[e.cls]
  return { lines, direct, byCategory, tax, loaders, escalation, base, contingency, total, low: Math.round(total * (1 + r.low)), high: Math.round(total * (1 + r.high)) }
}

/** Options for pricing against the rate table: the region selects region-specific rows, else base row × region factor. */
export interface RatePricing { region?: string; regionFactors?: Record<string, number> }

/**
 * Pick rate-table rows for a project's asset/work method: nearest diameter, matching terrain, and a row for the
 * project's region when the table has one (otherwise the base row; the caller applies the region factor).
 * Rows kept for a different region are never picked.
 */
export function ratesFor(project: Project, rates: UnitCostRate[], opts: RatePricing = {}): UnitCostRate[] {
  const region = opts.region ?? project.location.district
  const pool = rates.filter((r) => r.assetType === project.asset.type && r.workMethod === project.workMethod && (!r.region || r.region === region))
  const byCat: Record<string, UnitCostRate[]> = {}
  for (const r of pool) (byCat[r.categoryId + '|' + r.description.split(',')[0]] ||= []).push(r)
  return Object.values(byCat).map((group) =>
    group
      .slice()
      .sort((a, b) => score(a) - score(b))[0],
  )
  function score(r: UnitCostRate) {
    const d = r.diameterIn ? Math.abs(r.diameterIn - project.asset.diameterIn) : 0
    const t = r.terrain && r.terrain !== project.location.terrain ? 10 : 0
    const g = r.region === region ? -0.5 : 0 // a region row beats the equivalent base row
    return d + t + g
  }
}

/** Unit cost of a rate row in a region: a region-specific row prices as is; a base row is scaled by the region factor. */
export function regionalUnitCost(r: UnitCostRate, opts: RatePricing = {}): { unitCost: number; factor: number; regional: boolean } {
  if (r.region) return { unitCost: r.p50, factor: 1, regional: true }
  const f = opts.region && opts.regionFactors ? opts.regionFactors[opts.region] ?? 1 : 1
  return { unitCost: Math.round(r.p50 * f * 100) / 100, factor: f, regional: false }
}

/** Spread an amount across years between two dates using an S-curve (more spend mid-project). */
export function spreadByYear(total: Money, start: string, end: string): Record<string, Money> {
  const y0 = Number(start.slice(0, 4)), y1 = Math.max(Number(end.slice(0, 4)), y0)
  const years = Array.from({ length: y1 - y0 + 1 }, (_, i) => y0 + i)
  if (years.length === 1) return { [y0]: total }
  const w = years.map((_, i) => Math.sin(((i + 0.5) / years.length) * Math.PI))
  const W = sum(w)
  const out: Record<string, Money> = {}
  let acc = 0
  years.forEach((y, i) => {
    const v = i === years.length - 1 ? total - acc : Math.round((total * w[i]) / W)
    out[y] = v
    acc += v
  })
  return out
}

/** Line-level benchmark flag (ES-12): % off the rate-table median for its rate (in the estimate's region when given). */
export function benchmark(line: EstimateLine, rates: UnitCostRate[], opts?: RatePricing): { pct: number; flag: boolean; ref: number } | null {
  if (!line.rateId) return null
  const r = rates.find((x) => x.id === line.rateId)
  if (!r || !r.p50) return null
  const ref = opts ? regionalUnitCost(r, opts).unitCost : r.p50
  const pct = (line.unitCost - ref) / ref
  return { pct, flag: Math.abs(pct) > 0.25, ref }
}

/** Waterfall bridge between two estimates by category (ES-11). */
export function estimateBridge(a: Estimate, b: Estimate) {
  const ta = estimateTotals(a), tb = estimateTotals(b)
  const cats = Array.from(new Set([...Object.keys(ta.byCategory), ...Object.keys(tb.byCategory)]))
  const steps = cats.map((c) => ({ categoryId: c, delta: (tb.byCategory[c] || 0) - (ta.byCategory[c] || 0) })).filter((s) => s.delta !== 0)
  steps.push({ categoryId: CONT_CAT, delta: tb.contingency - ta.contingency })
  return { from: ta.total, to: tb.total, steps: steps.filter((s) => s.delta !== 0) }
}

/** Human-readable differences between two versions of the rate table (for the audit trail). */
export function diffRates(before: UnitCostRate[], after: UnitCostRate[]): string[] {
  const out: string[] = []
  const label = (r: UnitCostRate) => `${r.description}${r.region ? ` (${r.region})` : ''}`
  for (const a of after) {
    const b = before.find((x) => x.id === a.id)
    if (!b) { out.push(`Added ${label(a)}: ${a.unit}, P50 $${a.p50.toLocaleString('en-US')}`); continue }
    const ch = (['p10', 'p50', 'p90', 'unit', 'sampleSize', 'basisYear', 'description'] as const).filter((k) => b[k] !== a[k]).map((k) => `${k} ${b[k]} → ${a[k]}`)
    if (ch.length) out.push(`${label(a)}: ${ch.join(', ')}`)
  }
  for (const b of before) if (!after.some((x) => x.id === b.id)) out.push(`Removed ${label(b)}`)
  return out
}

/** Publish a new rate table: replaces the rows, bumps the version and records the note. Mutates the draft. */
export function publishRateTable(d: AppState, rates: UnitCostRate[], note: string, byId = d.currentUserId): { version: number; changes: string[] } {
  const changes = diffRates(d.rates, rates)
  const cfg = d.settings.estimating
  const version = cfg.rateTableVersion + 1
  d.rates = rates.map((r) => ({ ...r }))
  cfg.rateTableVersion = version
  cfg.rateTableHistory.push({ version, at: nowISO(), byId, note: note.trim() || `${changes.length} rate change${changes.length === 1 ? '' : 's'}` })
  for (const c of changes) d.audit.push({ id: uid('aud'), at: nowISO(), actorId: byId, entity: 'rate', entityId: `rate-table-v${version}`, action: 'update', summary: `Rate table v${version}: ${c}` })
  return { version, changes }
}

export interface LineReprice { line: EstimateLine; from: number; to: number; rowId?: string; status: 'repriced' | 'unchanged' | 'override' | 'quote' | 'manual' | 'missing' }

/** What each line would cost at today's table for the project's region. Quotes, analogs, judgment and overrides keep their price. */
export function repriceLines(s: Pick<AppState, 'settings' | 'rates'>, p: Project, lines: EstimateLine[]): LineReprice[] {
  const pr = pricingFor(s, p)
  return lines.map((l) => {
    if (!l.rateId) return { line: l, from: l.unitCost, to: l.unitCost, status: 'manual' as const }

    const r = s.rates.find((x) => x.id === l.rateId)
    if (!r) return { line: l, from: l.unitCost, to: l.unitCost, status: 'missing' as const }
    const row = rowForRegion(s.rates, r, pr.region!)
    const to = regionalUnitCost(row, pr).unitCost
    return { line: l, from: l.unitCost, to, rowId: row.id, status: Math.abs(to - l.unitCost) < 0.005 && row.id === l.rateId ? 'unchanged' as const : 'repriced' as const }
  })
}

/** Stamp the portfolio tables (loaders, escalation, contingency default, sales tax, region, rate version) onto an estimate. */
export function applyTables(s: Pick<AppState, 'settings' | 'rates'>, p: Project, e: Estimate): Estimate {
  const cls = computeClass(e.maturity, maturityItems(s))
  const esc = escalationPctFor(s, basisYearOf(s, e.lines), spendMidpoint(s, p))
  return {
    ...e,
    cls,
    loaders: currentLoaders(s),
    escalationPct: e.method === 'quick' ? e.escalationPct : esc,
    contingency: e.contingency.method === 'deterministic' ? { method: 'deterministic', pct: contingencyForClass(s, cls) } : e.contingency,
    salesTax: e.method === 'quick' ? e.salesTax : salesTaxFor(s, p),
    region: regionOf(p),
  }
}

/** Do the estimate's markups differ from the portfolio tables in force? */
export function tablesDrift(s: Pick<AppState, 'settings' | 'rates'>, p: Project, e: Estimate): string[] {
  const out: string[] = []
  const cur = currentLoaders(s)
  const same = cur.length === e.loaders.length && cur.every((x) => e.loaders.some((y) => y.name === x.name && Math.abs(y.pct - x.pct) < 0.001))
  if (!same) out.push(`loaders ${sum(e.loaders.map((l) => l.pct)).toFixed(1)}% → ${sum(cur.map((l) => l.pct)).toFixed(1)}%`)
  if (e.method !== 'quick') {
    const esc = escalationPctFor(s, basisYearOf(s, e.lines), spendMidpoint(s, p))
    if (Math.abs(esc - e.escalationPct) > 0.05) out.push(`escalation ${e.escalationPct}% → ${esc}%`)
    const tax = salesTaxFor(s, p)
    if (!e.salesTax || Math.abs(e.salesTax.pct - tax.pct) > 0.0005 || e.salesTax.categoryIds.join() !== tax.categoryIds.join()) out.push(`sales tax ${e.salesTax ? e.salesTax.pct + '%' : 'not applied'} → ${tax.pct}%`)
  }
  return out
}

const KEEP_ACTION = 'keep-rates'

/** Build the repriced version of an estimate (not pushed into state). */
export function repricedEstimate(s: AppState, e: Estimate, byId: string, note = ''): { est: Estimate; lines: LineReprice[]; mode: RepricePlan['mode'] } {
  const p = s.projects.find((x) => x.id === e.projectId)!
  const lr = repriceLines(s, p, e.lines)
  const mode: RepricePlan['mode'] = e.status === 'draft' ? 'update-draft' : 'new-version'
  const v = s.settings.estimating.rateTableVersion
  const from = pricedOnVersion(s, e)
  const lines = lr.map((x) => x.status === 'repriced' ? { ...x.line, id: mode === 'new-version' ? uid('ln') : x.line.id, unitCost: x.to, rateId: x.rowId ?? x.line.rateId } : { ...x.line, id: mode === 'new-version' ? uid('ln') : x.line.id })
  const nextVersion = Math.max(0, ...s.estimates.filter((x) => x.projectId === e.projectId).map((x) => x.version)) + 1
  const n = lr.filter((x) => x.status === 'repriced').length
  const assumption = `Repriced to rate table v${v} (from v${from}) for the ${regionOf(p)} region: ${n} rate-table line${n === 1 ? '' : 's'} updated; quotes, analogs, estimator judgment and overrides kept${note ? ` — ${note}` : ''}.`
  const base: Estimate = JSON.parse(JSON.stringify(e))
  const est = applyTables(s, p, {
    ...base,
    ...(mode === 'new-version' ? { id: uid('est'), version: nextVersion, status: 'draft' as const, createdAt: nowISO(), createdById: byId, approvedAt: undefined, approvedById: undefined, workflowInstanceId: undefined } : {}),
    lines,
    rateTableVersion: v,
    repricedFrom: { estimateId: e.id, fromVersion: e.version, fromRateTable: from, toRateTable: v },
    basis: { ...base.basis, assumptions: [...base.basis.assumptions.filter((a) => !/^Repriced to rate table v/.test(a)), assumption] },
  })
  return { est, lines: lr, mode }
}

/** Projects whose current estimate was priced on an older rate table version, with a before → after preview. */
export function repriceCandidates(s: AppState, byId = s.currentUserId): RepricePlan[] {
  const v = s.settings.estimating.rateTableVersion
  const out: RepricePlan[] = []
  for (const p of s.projects) {
    if (p.status === 'closed' || p.status === 'cancelled') continue
    const e = currentEstimateOf(s, p.id)
    if (!e || e.method === 'quick') continue // quick estimates price from the historical cost table, not the rate table
    const from = pricedOnVersion(s, e)
    if (from >= v) continue
    const { est, lines, mode } = repricedEstimate(s, e, byId)
    const hasDraft = s.estimates.some((x) => x.projectId === p.id && x.status === 'draft' && x.id !== e.id)
    const kept = [...s.audit].reverse().find((a) => a.entity === 'estimate' && a.entityId === e.id && a.action === KEEP_ACTION && a.summary.includes(`rate table v${v}`))
    const eligible = e.status !== 'in-review' && !hasDraft
    out.push({
      project: p, estimate: e, fromVersion: from, eligible, mode, preview: est, lines,
      reason: e.status === 'in-review' ? 'In review — reprice after the approval decision (or recall it)' : hasDraft ? 'Project has another open draft' : undefined,
      before: estimateTotals(e), after: estimateTotals(est),
      kept: kept ? { at: kept.at, byId: kept.actorId, note: kept.summary.split(' — ').slice(1).join(' — ') } : undefined,
    })
  }
  return out.sort((a, b) => a.project.code.localeCompare(b.project.code))
}

/** Reprice the chosen estimates: approved ones get a new draft version; open drafts are updated in place. Mutates. */
export function applyReprice(d: AppState, estimateIds: string[], note: string, byId = d.currentUserId): { created: Estimate[]; updated: Estimate[] } {
  const created: Estimate[] = [], updated: Estimate[] = []
  for (const id of estimateIds) {
    const e = d.estimates.find((x) => x.id === id)
    if (!e || e.status === 'in-review' || e.method === 'quick') continue
    const before = estimateTotals(e).total
    const { est, lines, mode } = repricedEstimate(d, e, byId, note)
    const after = estimateTotals(est).total
    const n = lines.filter((x) => x.status === 'repriced').length
    const p = d.projects.find((x) => x.id === e.projectId)!
    if (mode === 'update-draft') { Object.assign(e, est); updated.push(e) } else { d.estimates.push(est); created.push(est) }
    d.audit.push({ id: uid('aud'), at: nowISO(), actorId: byId, entity: 'estimate', entityId: est.id, projectId: p.id, action: 'reprice',
      summary: `${mode === 'update-draft' ? `Repriced draft v${e.version}` : `Created draft v${est.version} from v${e.version}`} on rate table v${est.rateTableVersion} (was v${est.repricedFrom!.fromRateTable}): ${n} line${n === 1 ? '' : 's'} repriced, current loaders, escalation ${est.escalationPct}%, sales tax ${est.salesTax?.pct ?? 0}% — $${(before / 1e6).toFixed(2)}M → $${(after / 1e6).toFixed(2)}M${note ? ` — ${note}` : ''}` })
  }
  return { created, updated }
}

/** Record that the estimating team keeps an estimate on its historical rates for this table version. Mutates. */
export function keepHistorical(d: AppState, estimateIds: string[], note: string, byId = d.currentUserId): number {
  const v = d.settings.estimating.rateTableVersion
  let n = 0
  for (const id of estimateIds) {
    const e = d.estimates.find((x) => x.id === id)
    if (!e) continue
    d.audit.push({ id: uid('aud'), at: nowISO(), actorId: byId, entity: 'estimate', entityId: e.id, projectId: e.projectId, action: KEEP_ACTION, summary: `Kept v${e.version} on historical rates (rate table v${pricedOnVersion(d, e)}) instead of repricing to rate table v${v}${note ? ` — ${note}` : ''}` })
    n++
  }
  return n
}

import type { CostPeriod } from '../types'

export interface EvmPoint { period: string; pv: number; ev: number; ac: number; cumPv: number; cumEv: number; cumAc: number }

/** Cumulative earned value series from monthly cost periods. */
export function evmSeries(periods: CostPeriod[]): EvmPoint[] {
  const sorted = periods.slice().sort((a, b) => a.period.localeCompare(b.period))
  let pv = 0, ev = 0, ac = 0
  return sorted.map((p) => {
    pv += p.planned; ev += p.earned; ac += p.actual
    return { period: p.period, pv: p.planned, ev: p.earned, ac: p.actual, cumPv: pv, cumEv: ev, cumAc: ac }
  })
}

export interface EvmMetrics { bac: number; pv: number; ev: number; ac: number; cpi: number; spi: number; cv: number; sv: number; eac: number; etc: number; vac: number; pctComplete: number; tcpi: number }

/** Standard EVM indices. BAC = control budget excluding contingency. */
export function evmMetrics(periods: CostPeriod[], bac: number): EvmMetrics {
  const s = evmSeries(periods)
  const last = s[s.length - 1] ?? { cumPv: 0, cumEv: 0, cumAc: 0 }
  const pv = last.cumPv, ev = last.cumEv, ac = last.cumAc
  const cpi = ac ? ev / ac : 1
  const spi = pv ? ev / pv : 1
  // VERIFY: EAC = AC + (BAC − EV) / CPI (CPI-based ETC); TCPI = (BAC − EV) / (BAC − AC) to complete at BAC. Confirm the EAC method the controls team uses.
  const eac = cpi ? ac + (bac - ev) / cpi : bac
  const tcpi = bac - ac ? (bac - ev) / (bac - ac) : 1
  return { bac, pv, ev, ac, cpi, spi, cv: ev - ac, sv: ev - pv, eac: Math.round(eac), etc: Math.round(eac - ac), vac: Math.round(bac - eac), pctComplete: bac ? ev / bac : 0, tcpi }
}

  const banded = QUICK_CATALOG.find((c) => c.asset === i.assetType)?.banded

}

/** One lump-sum line per category of the base rate's cost mix (the residual goes to the last line). */
export function mixLines(mix: Record<string, number>, direct: Money, label = 'Class 5 factor model'): EstimateLine[] {

  return entries.map(([cat, v], k) => {

    acc += amt

export interface PriceOpts { adjustPct?: number; basis?: 'p10' | 'p50' | 'p90'; salesTax?: Estimate['salesTax'] }

/** Price inputs with a model. Pure. */
export function priceFactor(s: AppState, model: FactorModel, i: FactorInputs, o: PriceOpts = {}): FactorResult {
  const { rate: base, match } = baseRateFor(model, i)
  const dv = driverValues(i)
  const qty = Math.max(0, i.qty)
  const baseline = (base?.rate ?? 0) * qty
  // VERIFY: size scale around the reference quantity: cost ∝ qty^scale, i.e. per-unit cost × (qty / refQty)^(scale − 1).
  const scale = base && qty > 0 && base.refQty > 0 ? Math.pow(qty / base.refQty, model.scaleExponent - 1) : 1
  // Only allowlisted drivers are ever read: a factor bound to anything else is ignored (and fails validation).
  const factors: FactorApplied[] = model.factors.filter((f) => DRIVER_KEYS.includes(f.driver) && factorApplies(f, i.assetType)).map((f) => {
    const level = levelOf(dv, f.driver)
    const m = f.levels.find((l) => l.value === level)?.multiplier ?? 1
    const effective = effectiveMultiplier(f, m)
    // VERIFY: a driver adds uncertainty only when it is off its baseline level; its cv is scaled by the weight.
    const sigma = Math.abs(effective - 1) > 1e-9 ? sigmaOf(Math.max(0, Math.min(1, f.weight)) * f.cv) : 0
    return { factor: f, level, levelLabel: levelLabel(f.driver, level), multiplier: m, effective, sigma }
  })
  const factorProduct = factors.reduce((a, f) => a * f.effective, 1)
  const rf = regionFactor(s, i.district)
  const ef = base ? escalationBetween(s, base.baseYear, i.midpointYear) : 1
  const parts: UncertaintyPart[] = [{ id: 'base', label: 'Base rate', sigma: sigmaOf(model.baseCv) }, ...factors.filter((f) => f.sigma > 0).map((f) => ({ id: f.factor.id, label: `${f.factor.name}: ${f.levelLabel}`, sigma: f.sigma }))]
  // VERIFY: combined uncertainty is lognormal with independent components: σ² = Σ ln(1 + cv²).
  const sigma = Math.sqrt(sum(parts.map((p) => p.sigma ** 2)))
  const z = o.basis === 'p90' ? Z90 : o.basis === 'p10' ? -Z90 : 0
  const adjust = (1 + (o.adjustPct ?? 0) / 100) * Math.exp(z * sigma)
  // VERIFY: direct = base rate × qty × size scale × Π factors × region × escalation × estimator adjustment.
  const directRaw = baseline * scale * factorProduct * rf * ef * adjust
  const direct = Math.round(directRaw)
  const lines = base ? mixLines(base.mix, direct) : []
  const salesTax = o.salesTax ? { ...o.salesTax, pct: o.salesTax.pct } : { pct: i.taxPct, counties: [], categoryIds: [...s.settings.estimating.taxableCategoryIds] }
  const loaders = currentLoaders(s)
  const cp = contingencyForClass(s, 5)
  const t = estimateTotals({ lines, loaders, escalationPct: 0, contingency: { method: 'deterministic', pct: cp }, cls: 5, salesTax })
  const cost = t.base
  const spread = (v: number, k: number) => Math.round(v * Math.exp(k * Z90 * sigma))

  // VERIFY: driver $ attribution = baseline × ln(multiplier) × (G − 1) / ln G (logarithmic-mean decomposition).
  // Itemized drivers: each multiplicative step's share of (direct − baseline), by the logarithmic mean so the
  // shares add up exactly and do not depend on the order the factors are applied in.
  const steps: { item: Omit<FactorItem, 'effect'>; g: number }[] = [
    { item: { id: 'scale', label: 'Size scale', kind: 'size', level: base ? `${qty.toLocaleString('en-US')} vs ${base.refQty.toLocaleString('en-US')} ${base.unit} reference` : '—', multiplier: scale }, g: scale },
    ...factors.map((f) => ({ item: { id: f.factor.id, label: f.factor.name, kind: f.factor.kind, level: f.levelLabel, multiplier: f.effective, weight: f.factor.weight }, g: f.effective })),
    { item: { id: 'region', label: 'Region factor', kind: 'region', level: i.district, multiplier: rf }, g: rf },
    { item: { id: 'escalation', label: 'Escalation', kind: 'escalation', level: base ? `${base.baseYear} → ${i.midpointYear}` : '—', multiplier: ef }, g: ef },
  ]
  if (Math.abs(adjust - 1) > 1e-9) steps.push({ item: { id: 'adjustment', label: 'Estimator adjustment', kind: 'adjustment', level: `${(o.adjustPct ?? 0) >= 0 ? '+' : ''}${o.adjustPct ?? 0}%${o.basis && o.basis !== 'p50' ? ` at ${o.basis.toUpperCase()}` : ''}`, multiplier: adjust }, g: adjust })
  const G = steps.reduce((a, x) => a * x.g, 1)
  const lnG = Math.log(G || 1)
  const L = Math.abs(lnG) > 1e-12 ? (G - 1) / lnG : 1
  const items: FactorItem[] = steps.map((x) => ({ ...x.item, effect: x.g > 0 ? Math.round(baseline * Math.log(x.g) * L) : 0 }))
  const residual = direct - Math.round(baseline) - sum(items.map((x) => x.effect))
  if (residual && items.length) { const k = items.reduce((bi, x, idx) => (Math.abs(x.effect) > Math.abs(items[bi].effect) ? idx : bi), 0); items[k] = { ...items[k], effect: items[k].effect + residual } }

  return {
    base, match, baseline: Math.round(baseline), scale, factors, factorProduct, regionFactor: rf, escalationFactor: ef, adjust,
    direct, tax: t.tax, loaders: t.loaders, loaderPct: sum(loaders.map((l) => l.pct)), contingencyPct: cp, contingency: t.contingency, cost, total: t.total,
    items, parts, sigma, p10: spread(t.total, -1), p50: t.total, p90: spread(t.total, 1), costP10: spread(cost, -1), costP90: spread(cost, 1),
    perUnit: qty ? t.total / qty : 0, lines, salesTax,
  }
}

/** The Class 5 rate-table (parametric) estimate for the same project, priced on today's tables. */
export function rateTableEstimate(s: AppState, p: Project): EstimateTotals | undefined {
  const lines = parametricLines(p, s.rates, pricingFor(s, p), scopeQuantities(s, p))
  if (!lines.length) return
  return estimateTotals({ lines, loaders: currentLoaders(s), escalationPct: escalationPctFor(s, basisYearOf(s, lines), spendMidpoint(s, p)), contingency: { method: 'deterministic', pct: contingencyForClass(s, 5) }, cls: 5, salesTax: salesTaxFor(s, p) })
}

// ───────────────────────────── Backtest
export interface BacktestPoint { id: string; code: string; name: string; assetType: string; predicted: Money; actual: Money; p10: Money; p90: Money; err: number; ape: number; inside: boolean }
export interface BacktestGroup { assetType: string; n: number; mape: number; bias: number; coverage: number }
export interface BacktestResult { n: number; mape: number; medianApe: number; bias: number; coverage: number; points: BacktestPoint[]; byAsset: BacktestGroup[] }

export const inputsOfRecord = (r: BacktestProject): FactorInputs => {
  const { terrain, ...site } = r.drivers
  return { assetType: r.assetType, workMethod: r.workMethod, diameterBand: r.diameterBand, terrain, district: r.district, qty: r.qty, unit: r.unit, midpointYear: r.midpointYear, site, taxPct: r.taxPct }
}

const median = (xs: number[]) => { const a = xs.slice().sort((x, y) => x - y); const m = Math.floor(a.length / 2); return a.length ? (a.length % 2 ? a[m] : (a[m - 1] + a[m]) / 2) : 0 }
const r1 = (n: number) => Math.round(n * 10) / 10
function stats(ps: BacktestPoint[]) {
  return { mape: r1(100 * sum(ps.map((p) => p.ape)) / (ps.length || 1)), bias: r1(100 * sum(ps.map((p) => p.err)) / (ps.length || 1)), coverage: r1(100 * ps.filter((p) => p.inside).length / (ps.length || 1)) }
}

/**
 * Predict every closed project in the backtest set and compare with its actual cost.
 * VERIFY: compares the model's expected cost (direct + sales tax + loaders, no contingency) with the final actual cost,
 * and its P10–P90 of that cost; contingency is a reserve, not a cost, so it is left out of both sides.
 */
export function backtest(s: AppState, model: FactorModel, records: BacktestProject[] = s.backtestProjects): BacktestResult {
  const points: BacktestPoint[] = []
  for (const rec of records) {
    const r = priceFactor(s, model, inputsOfRecord(rec))
    if (!r.base || !rec.actual) continue
    const err = (r.cost - rec.actual) / rec.actual
    points.push({ id: rec.id, code: rec.code, name: rec.name, assetType: rec.assetType, predicted: r.cost, actual: rec.actual, p10: r.costP10, p90: r.costP90, err, ape: Math.abs(err), inside: rec.actual >= r.costP10 && rec.actual <= r.costP90 })
  }
  const all = stats(points)
  const groups = Array.from(new Set(points.map((p) => p.assetType)))
  return { n: points.length, ...all, medianApe: r1(100 * median(points.map((p) => p.ape))), points, byAsset: groups.map((g) => { const ps = points.filter((p) => p.assetType === g); return { assetType: g, n: ps.length, ...stats(ps) } }) }
}

export const summarize = (bt: BacktestResult, gate: PublishGate): BacktestSummary => ({ at: nowISO(), n: bt.n, mape: bt.mape, medianApe: bt.medianApe, bias: bt.bias, coverage: bt.coverage, passed: gateCheck(bt, gate).ok })

export interface GateCheck { label: string; value: string; limit: string; ok: boolean }
/** The publish gate: accuracy, bias and calibrated range on the backtest. */
export function gateCheck(bt: Pick<BacktestResult, 'n' | 'mape' | 'bias' | 'coverage'>, g: PublishGate): { ok: boolean; checks: GateCheck[]; reasons: string[] } {
  const checks: GateCheck[] = [
    { label: 'Mean absolute % error', value: `${bt.mape.toFixed(1)}%`, limit: `≤ ${g.maxMape}%`, ok: bt.mape <= g.maxMape },
    { label: 'Bias', value: `${bt.bias > 0 ? '+' : ''}${bt.bias.toFixed(1)}%`, limit: `within ±${g.maxAbsBias}%`, ok: Math.abs(bt.bias) <= g.maxAbsBias },
    { label: 'Actuals inside P10–P90', value: `${bt.coverage.toFixed(1)}%`, limit: `${g.minCoverage}–${g.maxCoverage}%`, ok: bt.coverage >= g.minCoverage && bt.coverage <= g.maxCoverage },
    { label: 'Projects backtested', value: String(bt.n), limit: '≥ 20', ok: bt.n >= 20 },
  ]
  const reasons = checks.filter((c) => !c.ok).map((c) => `${c.label} ${c.value} (needs ${c.limit})`)
  return { ok: !reasons.length, checks, reasons }
}

/** Structural checks on a model before it can be submitted. */
export function validateModel(m: FactorModel): string[] {
  const out: string[] = []
  if (!(m.scaleExponent >= 0.5 && m.scaleExponent <= 1.2)) out.push('Scale exponent must be between 0.50 and 1.20')
  if (!(m.baseCv > 0 && m.baseCv < 1.5)) out.push('Base uncertainty (cv) must be between 0 and 1.5')
  for (const b of m.baseRates) if (!(b.rate > 0) || !(b.refQty > 0)) out.push(`Base rate ${rateName(b)} needs a rate and reference quantity above zero`)
  for (const f of m.factors) {
    if (!DRIVER_KEYS.includes(f.driver)) out.push(`${f.name}: driver "${String(f.driver)}" is not a physical, legal or logistical driver`)
    if (!(f.weight >= 0 && f.weight <= 1)) out.push(`${f.name}: weight must be 0–1`)
    if (!(f.cv >= 0 && f.cv < 1)) out.push(`${f.name}: cv must be 0–1`)
    if (f.levels.some((l) => !(l.multiplier > 0))) out.push(`${f.name}: every level needs a multiplier above zero`)
    const info = DRIVER_INFO[f.driver]
    if (info && Math.abs((f.levels.find((l) => l.value === info.baseline)?.multiplier ?? 1) - 1) > 1e-9) out.push(`${f.name}: the baseline level (${levelLabel(f.driver, info.baseline)}) must have multiplier 1.00`)
  }
  return out
}

// ───────────────────────────── Versions, diffs and lifecycle (mutate an immer draft)
const f2 = (n: number) => n.toFixed(2)
const rateName = (b: ModelBaseRate) => `${ASSET_TEXT(b.assetType)} · ${METHOD_TEXT[b.workMethod] ?? b.workMethod}${b.diameterBand !== 'n/a' ? ` · ${DIAMETER_BANDS.find((x) => x.id === b.diameterBand)?.label ?? b.diameterBand}` : ''}`
/** Human-readable differences between two model versions (weights, multipliers, cv, base rates, scale). */
export function diffModels(a: FactorModel, b: FactorModel): string[] {
  const out: string[] = []
  if (a.scaleExponent !== b.scaleExponent) out.push(`Scale exponent ${f2(a.scaleExponent)} → ${f2(b.scaleExponent)}`)
  if (a.baseCv !== b.baseCv) out.push(`Base uncertainty cv ${f2(a.baseCv)} → ${f2(b.baseCv)}`)
  for (const fb of b.factors) {
    const fa = a.factors.find((x) => x.id === fb.id)
    if (!fa) { out.push(`Added factor ${fb.name} (${DRIVER_INFO[fb.driver]?.label ?? fb.driver}, weight ${f2(fb.weight)})`); continue }
    if (fa.weight !== fb.weight) out.push(`${fb.name}: weight ${f2(fa.weight)} → ${f2(fb.weight)}`)
    if (fa.cv !== fb.cv) out.push(`${fb.name}: cv ${f2(fa.cv)} → ${f2(fb.cv)}`)
    for (const lb of fb.levels) {
      const la = fa.levels.find((x) => x.value === lb.value)
      if (la && la.multiplier !== lb.multiplier) out.push(`${fb.name} · ${lb.label}: ×${f2(la.multiplier)} → ×${f2(lb.multiplier)}`)
    }
    if ((fa.appliesTo ?? []).join() !== (fb.appliesTo ?? []).join()) out.push(`${fb.name}: applies to ${(fb.appliesTo ?? ['all assets']).join(', ')}`)
  }
  for (const fa of a.factors) if (!b.factors.some((x) => x.id === fa.id)) out.push(`Removed factor ${fa.name}`)
  for (const rb of b.baseRates) {
    const ra = a.baseRates.find((x) => x.id === rb.id)
    if (!ra) out.push(`Added base rate ${rateName(rb)}`)
    else if (ra.rate !== rb.rate || ra.refQty !== rb.refQty) out.push(`Base rate ${rateName(rb)}: $${Math.round(ra.rate).toLocaleString('en-US')} → $${Math.round(rb.rate).toLocaleString('en-US')}/${rb.unit}${ra.refQty !== rb.refQty ? ` (ref ${ra.refQty} → ${rb.refQty})` : ''}`)
  }
  return out
}

const audit = (d: AppState, m: FactorModel, action: string, summary: string, byId: string) => d.audit.push({ id: uid('aud'), at: nowISO(), actorId: byId, entity: 'factor-model', entityId: m.id, action, summary })

/** Start a new draft version from the published model (or a given version). Mutates; returns the draft. */
export function newDraft(d: AppState, byId = d.currentUserId, fromId?: string): FactorModel | undefined {
  if (openDraft(d)) return
  const src = (fromId && d.factorModels.find((m) => m.id === fromId)) || publishedModel(d) || modelsByVersion(d)[0]
  if (!src) return
  const version = Math.max(0, ...d.factorModels.map((m) => m.version)) + 1
  const m: FactorModel = { ...JSON.parse(JSON.stringify(src)), id: uid('fm'), version, status: 'draft', createdById: byId, createdAt: nowISO(), parentVersion: src.version, notes: '', submittedAt: undefined, approvedById: undefined, approvedAt: undefined, retiredAt: undefined, workflowInstanceId: undefined, backtest: undefined }
  d.factorModels.push(m)
  audit(d, m, 'create', `Factor model v${version} drafted from v${src.version}`, byId)
  return m
}

/** Save edits to the open draft. Returns what changed (also written to the audit trail). */
export function saveDraft(d: AppState, edited: FactorModel, byId = d.currentUserId): string[] {
  const m = d.factorModels.find((x) => x.id === edited.id)
  if (!m || m.status !== 'draft') return []
  const changes = diffModels(m, edited)
  const notesChanged = m.notes !== edited.notes
  m.baseRates = JSON.parse(JSON.stringify(edited.baseRates))
  m.factors = JSON.parse(JSON.stringify(edited.factors))
  m.scaleExponent = edited.scaleExponent
  m.baseCv = edited.baseCv
  m.notes = edited.notes
  m.name = edited.name
  m.backtest = undefined
  if (changes.length) audit(d, m, 'update', `Factor model v${m.version} draft: ${changes.join('; ')}`, byId)
  else if (notesChanged) audit(d, m, 'update', `Factor model v${m.version} draft: notes updated`, byId)
  return changes
}

/** Discard the open draft (kept as retired: records are never hard-deleted). */
export function discardDraft(d: AppState, id: string, byId = d.currentUserId) {
  const m = d.factorModels.find((x) => x.id === id)
  if (!m || m.status !== 'draft') return
  m.status = 'retired'
  m.retiredAt = nowISO()
  m.notes = `${m.notes ? m.notes + ' ' : ''}(Discarded draft)`.trim()
  audit(d, m, 'discard', `Factor model v${m.version} draft discarded`, byId)
}

/** Record that a draft passed the gate and went for approval. */
export function markSubmitted(d: AppState, id: string, summary: BacktestSummary, byId = d.currentUserId) {
  const m = d.factorModels.find((x) => x.id === id)
  if (!m) return
  m.status = 'in-review'
  m.submittedAt = nowISO()
  m.backtest = summary
  audit(d, m, 'submit', `Factor model v${m.version} submitted for approval — backtest MAPE ${summary.mape}%, bias ${summary.bias > 0 ? '+' : ''}${summary.bias}%, P10–P90 coverage ${summary.coverage}% (n = ${summary.n})`, byId)
}

/** Approval: publish the model and retire the version it replaces. Called by the workflow completion hook. */
export function publishModel(d: AppState, id: string, approverId: string) {
  const m = d.factorModels.find((x) => x.id === id)
  if (!m) return
  for (const o of d.factorModels) if (o.status === 'published' && o.id !== id) { o.status = 'retired'; o.retiredAt = nowISO(); audit(d, o, 'retire', `Factor model v${o.version} retired — replaced by v${m.version}`, approverId) }
  m.status = 'published'
  m.approvedById = approverId
  m.approvedAt = nowISO()
  audit(d, m, 'publish', `Factor model v${m.version} approved and published`, approverId)
}

/** Returned or rejected in review: back to an editable draft. */
export function returnModel(d: AppState, id: string, byId = 'system') {
  const m = d.factorModels.find((x) => x.id === id)
  if (!m || m.status !== 'in-review') return
  m.status = 'draft'
  audit(d, m, 'return', `Factor model v${m.version} returned to draft`, byId)
}

// ───────────────────────────── Monte Carlo
export interface FactorMonteCarlo {
  iterations: number
  seed: number
  p: { P10: Money; P50: Money; P80: Money; P90: Money }
  mean: Money
  histogram: { x: number; n: number }[]
  scurve: { pct: number; value: Money }[] // cumulative probability → cost
  tornado: { id: string; label: string; low: Money; high: Money; swing: Money; share: number }[]
}

/**
 * Seeded Monte Carlo of a priced estimate: draws the base-rate and each active driver's uncertainty (lognormal,
 * independent) around the point estimate. Pure — the same inputs and seed give the same answer.
 */
export function monteCarloFactor(r: Pick<FactorResult, 'total' | 'parts'>, iterations = 5000, seed = 11): FactorMonteCarlo {
  const R = rng(seed)
  const normal = () => { const u = Math.max(1e-12, R.next()), v = R.next(); return Math.sqrt(-2 * Math.log(u)) * Math.cos(2 * Math.PI * v) }
  const xs: number[] = new Array(iterations)
  for (let k = 0; k < iterations; k++) {
    let e = 0
    for (const p of r.parts) e += p.sigma * normal()
    // VERIFY: draws are centred so the point estimate is the median of the distribution.
    xs[k] = r.total * Math.exp(e)
  }
  xs.sort((a, b) => a - b)
  const q = (p: number) => Math.round(xs[Math.min(xs.length - 1, Math.max(0, Math.floor(p * xs.length)))])
  const lo = xs[0], hi = xs[xs.length - 1]
  const bins = 30
  const w = (hi - lo) / bins || 1
  const histogram = Array.from({ length: bins }, (_, k) => ({ x: Math.round(lo + w * (k + 0.5)), n: 0 }))
  for (const x of xs) histogram[Math.min(bins - 1, Math.floor((x - lo) / w))].n++
  const scurve = Array.from({ length: 21 }, (_, k) => ({ pct: k * 5, value: q(Math.min(0.999, Math.max(0.001, k / 20))) }))
  const tot = sum(r.parts.map((p) => p.sigma ** 2)) || 1
  const tornado = r.parts.map((p) => {
    const low = Math.round(r.total * Math.exp(-Z90 * p.sigma)), high = Math.round(r.total * Math.exp(Z90 * p.sigma))
    return { id: p.id, label: p.label, low, high, swing: high - low, share: p.sigma ** 2 / tot }
  }).sort((a, b) => b.swing - a.swing)
  return { iterations, seed, p: { P10: q(0.1), P50: q(0.5), P80: q(0.8), P90: q(0.9) }, mean: Math.round(sum(xs) / (xs.length || 1)), histogram, scurve, tornado }
}

// ───────────────────────────── Basis of estimate text
const ASSET_TEXT = (a: string) => QUICK_CATALOG.find((c) => c.asset === a)?.label ?? a
const METHOD_TEXT: Record<string, string> = { 'replace-open-trench': 'open-trench replacement', 'replace-hdd': 'replacement by horizontal directional drill', hydrotest: 'hydrostatic test', 'valve-automation': 'valve automation', 'station-rebuild': 'station rebuild', 'compressor-replacement': 'compressor replacement', abandon: 'abandonment', 'inline-inspection': 'in-line inspection' }
const rateText = (v: number, u: string) => `$${v >= 1000 ? Math.round(v).toLocaleString('en-US') : v.toFixed(0)}/${u}`

/**
 * Basis of estimate generated from the pricing. Draft wording: an estimator must check it before it is relied on.
 * VERIFY: BOE wording (scope basis, assumptions, exclusions, contingency rationale, class justification).
 */
export function factorBoe(model: Pick<FactorModel, 'version' | 'baseCv' | 'scaleExponent'>, i: FactorInputs, r: FactorResult, rateTable?: Money, adjustment?: { pct: number; reason: string; note?: string; basis?: string }): BasisOfEstimate {
  const b = r.base
  const band = i.diameterBand !== 'n/a' ? `, ${DIAMETER_BANDS.find((x) => x.id === i.diameterBand)?.label ?? i.diameterBand}` : ''
  const off = r.items.filter((x) => x.kind !== 'size' && x.kind !== 'region' && x.kind !== 'escalation' && x.kind !== 'adjustment' && Math.abs(x.multiplier - 1) > 1e-9)
  const assumptions = [
    b ? `Base direct rate ${rateText(b.rate, b.unit)} (${b.baseYear} dollars, ${b.n} closed projects) at a reference quantity of ${b.refQty.toLocaleString('en-US')} ${UNIT_LABEL[b.unit]}; size scale exponent ${model.scaleExponent.toFixed(2)} gives ×${r.scale.toFixed(3)} for ${i.qty.toLocaleString('en-US')} ${UNIT_LABEL[i.unit]}.` : 'No base rate in the model for this asset and method.',
    off.length ? `Cost drivers off their baseline level: ${off.map((x) => `${x.label} (${x.level}) ×${x.multiplier.toFixed(3)}, ${x.effect >= 0 ? '+' : '−'}${money(Math.abs(x.effect))}`).join('; ')}.` : 'All physical, legal and logistical drivers at their baseline levels.',
    `${i.district} regional factor ×${r.regionFactor.toFixed(2)}; escalated ${b?.baseYear ?? '—'} → ${i.midpointYear} spend midpoint ×${r.escalationFactor.toFixed(3)}.`,
    `Sales tax ${r.salesTax.pct}% on taxable material; loaders ${r.loaderPct.toFixed(1)}% at current rates; contingency ${r.contingencyPct}% (Class 5 default).`,
  ]
  if (rateTable) assumptions.push(`Cross-check: the Class 5 rate-table estimate for the same scope is ${money(rateTable)} (${r.total >= rateTable ? '+' : '−'}${Math.abs((r.total / rateTable - 1) * 100).toFixed(0)}% from this estimate's basis).`)
  if (adjustment && (adjustment.pct || (adjustment.basis && adjustment.basis !== 'p50'))) assumptions.push(`Estimator adjustment ${adjustment.pct >= 0 ? '+' : ''}${adjustment.pct}%${adjustment.basis && adjustment.basis !== 'p50' ? `, priced at ${adjustment.basis.toUpperCase()}` : ''}: ${adjustment.reason}${adjustment.note ? ` — ${adjustment.note}` : ''}.`)
  return {
    scopeBasis: `${ASSET_TEXT(i.assetType)}, ${METHOD_TEXT[i.workMethod] ?? i.workMethod}${band}, ${i.qty.toLocaleString('en-US')} ${UNIT_LABEL[i.unit]}, ${i.district} region. Priced with Class 5 factor model v${model.version}.`,
    assumptions,
    exclusions: ['Scope not represented by the model drivers', 'Land acquisition by condemnation', 'Unknown contamination remediation'],
    contingencyRationale: `Class 5 default ${r.contingencyPct}%. Model range P10–P90 ${money(r.p10)}–${money(r.p90)} from base-rate uncertainty (cv ${model.baseCv.toFixed(2)}) and the uncertainty of each driver off its baseline, combined as a lognormal distribution.`,
    classJustification: 'Class 5: need, driver and asset identified; no design. Parametric factor model on physical, legal and logistical cost drivers.',
  }
}

  const t = p ? salesTaxFor(d, p) : { pct: i.taxPct, counties: [], categoryIds: [...d.settings.estimating.taxableCategoryIds] }

/**
 * Create a draft Class 5 quick estimate on a project priced with the published factor model. Mutates the draft; returns
 * the estimate (route it with the class5-review workflow). Undefined when there is no published model or base rate.
 */
export function createFactorEstimate(d: AppState, pid: string, i: FactorInputs, requestNote: string, byId = d.currentUserId, needBy?: string): Estimate | undefined {
  const model = publishedModel(d)
  const p = d.projects.find((x) => x.id === pid)
  if (!model || !p) return
  const r = priceFactor(d, model, i, { salesTax: salesTaxOf(d, p, i) })
  if (!r.base) return
  const rt = rateTableEstimate(d, p)?.total
  const version = Math.max(0, ...d.estimates.filter((e) => e.projectId === pid).map((e) => e.version)) + 1
  const e: Estimate = {
    id: uid('est'), projectId: pid, version, title: 'Class 5 quick estimate', cls: 5, status: 'draft', method: 'quick',
    createdAt: nowISO(), createdById: byId,
    lines: r.lines, maturity: { 'need-defined': true },
    loaders: currentLoaders(d), escalationPct: 0, contingency: { method: 'deterministic', pct: r.contingencyPct }, salesTax: r.salesTax, region: i.district,
    basis: factorBoe(model, i, r, rt),
    quick: { inputs: JSON.parse(JSON.stringify(i)), historicalCostId: r.base.sourceRowId ?? r.base.id, basis: 'p50', baseRate: r.base.rate, regionFactor: r.regionFactor, escalationFactor: r.escalationFactor, direct: r.direct, range: { low: r.p10, high: r.p90 }, requestNote, needBy },
    factor: { modelId: model.id, modelVersion: model.version, baseRateId: r.base.id, baseline: r.baseline, items: r.items, sigma: r.sigma, p10: r.p10, p50: r.p50, p90: r.p90, rateTable: rt },
  }
  d.estimates.push(e)
  d.audit.push({ id: uid('aud'), at: e.createdAt, actorId: byId, entity: 'estimate', entityId: e.id, projectId: pid, action: 'create', summary: `Class 5 quick estimate v${version} priced with factor model v${model.version}: $${(estimateTotals(e).total / 1e6).toFixed(1)}M (P10–P90 $${(r.p10 / 1e6).toFixed(1)}M–$${(r.p90 / 1e6).toFixed(1)}M)` })
  return e
}

/** Price a saved factor estimate again (same model version) with an adjustment, without changing it. */

// Submitting a factor model for approval: the publish gate (structure + backtest thresholds), then the
// factor-model-publish workflow (estimating lead approves; approval publishes it and retires the prior version).
import type { AppState } from '../types'
import { backtest, gateCheck, markSubmitted, summarize, validateModel } from './factorModel'
import { actOnWorkflow, recallWorkflow, startWorkflow } from './workflow'

export interface SubmitResult { ok: boolean; reasons: string[]; instId?: string }

/** Why a model cannot be submitted right now (empty when it can). Runs the backtest. */
export function submitBlockers(s: AppState, id: string): string[] {
  const m = s.factorModels.find((x) => x.id === id)
  if (!m) return ['Model not found']
  if (m.status !== 'draft') return [`v${m.version} is ${m.status}; only a draft can be submitted`]
  const v = validateModel(m)
  if (v.length) return v
  return gateCheck(backtest(s, m), s.settings.factorModel.gate).reasons
}

/** Gate, then route for approval. Mutates the draft. Nothing changes when the gate fails. */
export function submitFactorModel(d: AppState, id: string, byId = d.currentUserId, note = ''): SubmitResult {
  const reasons = submitBlockers(d, id)
  if (reasons.length) return { ok: false, reasons }
  const m = d.factorModels.find((x) => x.id === id)!
  const bt = backtest(d, m)
  markSubmitted(d, id, summarize(bt, d.settings.factorModel.gate), byId)
  const inst = startWorkflow(d, 'factor-model-publish', {
    title: `Factor model v${m.version}`, recordType: 'factor-model', recordId: id, startedById: byId,
    data: { note: note || `Backtest MAPE ${bt.mape}%, bias ${bt.bias}%, coverage ${bt.coverage}%`, mape: bt.mape, bias: bt.bias, coverage: bt.coverage },
  })
  if (!inst) return { ok: false, reasons: ['No published factor-model-publish process'] }
  const slot = inst.active[0]
  if (slot && slot.nodeId === 'prep' && slot.assigneeIds.includes(byId)) actOnWorkflow(d, inst.id, 'prep', byId, 'submit', note || 'Submitted for approval')
  return { ok: true, reasons: [], instId: inst.id }
}

/** The approval step sent it back to the submitter (workflow waiting at the submit step again). */
export function returnedForRevision(s: AppState, id: string) {
  const m = s.factorModels.find((x) => x.id === id)
  const inst = m?.workflowInstanceId ? s.workflows.find((w) => w.id === m.workflowInstanceId) : undefined
  if (!m || m.status !== 'in-review' || !inst || inst.status !== 'running') return
  const slot = inst.active.find((a) => a.nodeId === 'prep')
  if (!slot) return
  return { inst, slot, event: [...inst.history].reverse().find((h) => h.action === 'return') }
}

/** Withdraw a model from review (or after it was returned) so it can be edited again. Mutates. */
export function withdrawFactorModel(d: AppState, id: string, byId = d.currentUserId): boolean {
  const m = d.factorModels.find((x) => x.id === id)
  if (!m || m.status !== 'in-review' || !m.workflowInstanceId) return false
  recallWorkflow(d, m.workflowInstanceId, byId)
  return d.factorModels.find((x) => x.id === id)?.status === 'draft'
}

export type BasisKind = 'budget' | 'estimate' | 'none'

/** Latest estimate that still counts (approved preferred, then in review / draft). */
export function latestEstimate(s: AppState, pid: string) {
  const es = s.estimates.filter((e) => e.projectId === pid && e.status !== 'superseded' && e.status !== 'rejected')
  const appr = es.filter((e) => e.status === 'approved').sort((a, b) => b.version - a.version)[0]
  return appr ?? es.sort((a, b) => b.version - a.version)[0]
}

/** Budget (or, before a budget exists, the latest estimate) by forecast line, contingency separate. */
export function basisByLine(s: AppState, pid: string): { kind: BasisKind; byLine: Record<string, Money>; contingency: Money; label: string } {
  if (activeBudget(s, pid)) {
    const b = budgetByLine(s, pid)
    return { kind: 'budget', byLine: b.byLine, contingency: b.contingency, label: 'current budget' }
  }
  const e = latestEstimate(s, pid)
  if (!e) return { kind: 'none', byLine: {}, contingency: 0, label: 'no estimate yet' }
  const t = estimateTotals(e)
  const l = toLines(s, t.byCategory)
  return { kind: 'estimate', byLine: l.byLine, contingency: t.contingency, label: `estimate v${e.version} (Class ${e.cls})` }
}

/** Same basis rolled up to WBS functions. */
export function basisByFunction(s: AppState, pid: string): { kind: BasisKind; byFn: Record<string, Money>; contingency: Money; label: string } {
  if (activeBudget(s, pid)) {
    const b = budgetByFunction(s, pid)
    return { kind: 'budget', byFn: b.byFn, contingency: b.contingency, label: 'current budget' }
  }
  const e = latestEstimate(s, pid)
  if (!e) return { kind: 'none', byFn: {}, contingency: 0, label: 'no estimate yet' }
  const t = estimateTotals(e)
  return { kind: 'estimate', byFn: toFunctions(s, t.byCategory).byFn, contingency: t.contingency, label: `estimate v${e.version} (Class ${e.cls})` }
}

// ───────────────────────────── Internal orders

export const ioLabel = (io?: InternalOrder) => (io ? `${io.number} · ${io.type === 'capital' ? 'Capital' : 'O&M'}` : '—')

export interface FnCoverage { fnId: string; code: string; name: string; budget: Money; ios: InternalOrder[]; status: 'ok' | 'pending' | 'gap' | 'duplicate' | 'closed'; note: string }

/**
 * The feedback loop once IOs exist: every WBS function with budget must be carried by exactly one live IO.
 * pending = only a requested IO carries it; closed = only closed IOs; duplicate = more than one live IO.
 */
export function ioCoverage(s: AppState, p: Project): { rows: FnCoverage[]; gaps: FnCoverage[]; basis: BasisKind; basisLabel: string } {
  const b = basisByFunction(s, p.id)
  const ios = p.finance?.ios ?? []
  const rows: FnCoverage[] = s.settings.wbsFunctions.map((fn) => {
    const budget = b.byFn[fn.id] || 0
    const carriers = ios.filter((io) => io.functionIds.includes(fn.id))
    const live = carriers.filter((io) => io.status !== 'closed')
    let status: FnCoverage['status'] = 'ok'
    let note = ''
    if (!carriers.length) { status = budget > 0 ? 'gap' : 'ok'; note = budget > 0 ? 'Budget with no internal order to charge' : 'No budget' }
    else if (!live.length) { status = budget > 0 && p.status !== 'closed' ? 'closed' : 'ok'; note = 'Only closed IOs carry it' }
    else if (live.length > 1) { status = 'duplicate'; note = `${live.length} live IOs carry it — charges could split` }
    else if (live[0].status === 'requested') { status = 'pending'; note = `IO ${live[0].number} requested, not yet open in SAP` }
    else note = `Charges to ${live[0].number}`
    return { fnId: fn.id, code: fn.code, name: fn.name, budget, ios: carriers, status, note }
  })
  return { rows, gaps: rows.filter((r) => r.budget > 0 && r.status !== 'ok'), basis: b.kind, basisLabel: b.label }
}

/** Capital vs O&M: the split implied by the IOs (budget each IO type carries) vs the scope statement's split. */
export function capitalSplit(s: AppState, p: Project): { scopeCapitalPct?: number; ioCapitalPct?: number; capital: Money; om: Money; unassigned: Money; deltaPts?: number } {
  const b = basisByFunction(s, p.id)
  const ios = (p.finance?.ios ?? []).filter((io) => io.status !== 'closed' || p.status === 'closed')
  let capital = 0, om = 0, unassigned = 0
  for (const [fn, amt] of Object.entries(b.byFn)) {
    if (!amt) continue
    const io = ios.find((x) => x.functionIds.includes(fn))
    if (!io) unassigned += amt
    else if (io.type === 'capital') capital += amt
    else om += amt
  }
  const tot = capital + om
  const ioCapitalPct = tot ? Math.round((capital / tot) * 1000) / 10 : undefined
  const scopeCapitalPct = p.scope.capitalPct
  return { scopeCapitalPct, ioCapitalPct, capital, om, unassigned, deltaPts: ioCapitalPct !== undefined && scopeCapitalPct !== undefined ? Math.round((ioCapitalPct - scopeCapitalPct) * 10) / 10 : undefined }
}

/** Next internal order number in the project's series (71nnnnXX capital, 72nnnnXX O&M). */
export function nextIoNumber(p: Project, type: InternalOrder['type']): string {
  const n = p.code.replace(/\D/g, '')
  const prefix = (type === 'capital' ? '71' : '72') + n
  const used = (p.finance?.ios ?? []).filter((io) => io.number.startsWith(prefix)).map((io) => Number(io.number.slice(prefix.length)) || 0)
  return prefix + String((used.length ? Math.max(...used) : 0) + 1).padStart(2, '0')
}

export interface CommitmentRow {
  c: Contract
  committed: Money // original commitment for this project
  approvedChanges: Money
  pendingChanges: Money // RFI / CCOs in review
  current: Money // committed + approved changes
  invoiced: Money
  remaining: Money // current − invoiced
  poShare?: Money // PO total × % of PO (what the PM planned to use)
  usedPct?: number // current commitment as % of the PO
  overShare: boolean // current commitment (after approved CCOs) exceeds the planned share: raise % of PO

}

export function commitmentRow(s: AppState, c: Contract): CommitmentRow {
  const ccos = s.commitmentChanges.filter((x) => x.contractId === c.id).sort((a, b) => b.code.localeCompare(a.code))
  const current = c.value + c.changeOrders
  const poShare = c.poTotal && c.pctOfPo !== undefined ? Math.round((c.poTotal * c.pctOfPo) / 100) : undefined
  return {
    c, committed: c.value, approvedChanges: c.changeOrders,
    pendingChanges: sum(ccos.filter((x) => x.status === 'in-review').map((x) => x.amount)),
    current, invoiced: c.invoiced, remaining: current - c.invoiced, poShare, usedPct: c.poTotal ? Math.round((current / c.poTotal) * 1000) / 10 : undefined,
    overShare: poShare !== undefined && current > poShare * 1.005, ccos,
  }
}

export interface LineCoverage { lineId: string; code: string; name: string; budget: Money; committed: Money; contractIds: string[]; status: 'covered' | 'company' | 'gap' }

/** "Every estimate line must be assigned to a vendor commitment": lines with budget and no commitment are gaps. */
export function lineCoverage(s: AppState, pid: string): { rows: LineCoverage[]; gaps: LineCoverage[]; basis: BasisKind; basisLabel: string; uncovered: Money } {
  const b = basisByLine(s, pid)
  const cons = s.contracts.filter((c) => c.projectId === pid)
  const rows: LineCoverage[] = forecastLines(s).map((l) => {
    const budget = b.byLine[l.id] || 0
    const mine = cons.filter((c) => c.lineIds?.includes(l.id))
    // a commitment's current value is attributed to its lines pro-rata to their budget
    const committed = sum(mine.map((c) => {
      const lines = c.lineIds ?? []
      const tot = sum(lines.map((x) => b.byLine[x] || 0))
      return Math.round(((c.value + c.changeOrders) * (tot ? budget / tot : 1 / Math.max(1, lines.length))))
    }))
    const status: LineCoverage['status'] = mine.length ? 'covered' : NON_COMMITMENT_LINES[l.id] ? 'company' : 'gap'
    return { lineId: l.id, code: l.code, name: l.name, budget, committed, contractIds: mine.map((c) => c.id), status }
  }).filter((r) => r.budget > 0 || r.contractIds.length)
  const gaps = rows.filter((r) => r.status === 'gap' && r.budget > 0)
  return { rows, gaps, basis: b.kind, basisLabel: b.label, uncovered: sum(gaps.map((g) => g.budget)) }
}

export interface StageDeliverables { stageIndex: number; stage: string; gate: string; total: number; done: number; submitted: number; inProgress: number; pct: number }

/** Deliverable completeness from the lifecycle template's gate checklists (conditions evaluated per project). */
export function deliverableCompleteness(s: AppState, p: Project): { current: StageDeliverables; toDate: { total: number; done: number; pct: number }; stages: StageDeliverables[] } {
  const tpl = templateFor(s, p)
  const stages: StageDeliverables[] = tpl.stages.map((st, i) => {
    const defs = requiredDefs(s, p, i)
    const dl = s.deliverables.filter((x) => x.projectId === p.id && x.stageIndex === i)
    const st_ = (defId: string) => dl.find((x) => x.defId === defId)?.status
    const done = defs.filter((d) => ['accepted', 'waived'].includes(st_(d.id) ?? '')).length
    const submitted = defs.filter((d) => st_(d.id) === 'submitted').length
    const inProgress = defs.filter((d) => st_(d.id) === 'in-progress' || st_(d.id) === 'returned').length
    return { stageIndex: i, stage: st.name, gate: st.gate.name, total: defs.length, done, submitted, inProgress, pct: defs.length ? Math.round((done / defs.length) * 100) : 100 }
  })
  const cur = stages[Math.min(p.stageIndex, stages.length - 1)]
  const upto = stages.slice(0, p.stageIndex + 1)
  const total = sum(upto.map((x) => x.total)), done = sum(upto.map((x) => x.done))
  return { current: cur, toDate: { total, done, pct: total ? Math.round((done / total) * 100) : 100 }, stages }
}

export function templateFor(s: AppState, p: Project): LifecycleTemplate {
  const prog = s.programs.find((x) => x.id === p.programId)
  return s.templates.find((t) => t.id === prog?.lifecycleTemplateId) ?? s.templates[0]
}
export const stageName = (s: AppState, p: Project) => templateFor(s, p).stages[p.stageIndex]?.name ?? '—'

/** Deliverable definitions that apply to this project at a stage (conditions evaluated, SG-03). */
export function requiredDefs(s: AppState, p: Project, stageIndex = p.stageIndex): DeliverableDef[] {
  const st = templateFor(s, p).stages[stageIndex]
  return st ? st.gate.deliverables.filter((d) => evalCondition(d.condition, p)) : []
}

/** Create missing deliverable records for the project's current stage. */
export function ensureDeliverables(d: AppState, p: Project, stageIndex = p.stageIndex) {
  const defs = requiredDefs(d, p, stageIndex)
  const team = p.team
  for (const def of defs) {
    if (d.deliverables.some((x) => x.projectId === p.id && x.defId === def.id && x.stageIndex === stageIndex)) continue
    d.deliverables.push({
      id: uid('dlv'),
      projectId: p.id,
      stageIndex,
      defId: def.id,
      status: 'not-started',
      ownerId: ownerForRole(d, p, def.ownerRole),
      reviewerId: ownerForRole(d, p, def.reviewerRole),
      due: addDays(d.settings.asOf, 45),
      version: 0,
      evidence: [],
      updatedAt: nowISO(),
    })
  }
  void team
}

/** Map a role to a person: project team first, else first person with that role. */
export function ownerForRole(s: AppState, p: Project, role: string): string | undefined {
  const map: Record<string, keyof Project['team']> = {
    pm: 'pm', sponsor: 'sponsor', engineer: 'engineer', estimator: 'estimator', 'project-controls': 'projectControls',
    scheduler: 'scheduler', 'construction-manager': 'constructionManager', 'safety-advisor': 'safety', environmental: 'environmental', land: 'land',
  }
  const pos = map[role]
  if (pos && p.team[pos]) return p.team[pos]
  return s.people.find((x) => x.roles.includes(role as any))?.id
}

export interface Readiness {
  pct: number
  total: number
  done: number
  missing: DeliverableDef[]
  estimateRequired?: number
  estimateClass?: number
  estimateOk: boolean
  highRisks: number
  ready: boolean
  blockers: string[]
  missingInfo: string[]
}

/** Gate readiness score (SG-04). */
export function readiness(s: AppState, p: Project): Readiness {
  const defs = requiredDefs(s, p)
  const dl = s.deliverables.filter((x) => x.projectId === p.id && x.stageIndex === p.stageIndex)
  const doneDefs = defs.filter((def) => dl.some((x) => x.defId === def.id && (x.status === 'accepted' || x.status === 'waived')))
  const gate = templateFor(s, p).stages[p.stageIndex]?.gate
  const est = s.estimates.filter((e) => e.projectId === p.id && e.status === 'approved').sort((a, b) => a.version - b.version).pop()
  const estimateOk = !gate?.requiredEstimateClass || (!!est && est.cls <= gate.requiredEstimateClass)
  const highRisks = s.risks.filter((r) => r.projectId === p.id && isActive(r) && riskScore(r) >= 15 && r.responses.length === 0).length
  const pct = defs.length ? Math.round((doneDefs.length / defs.length) * 100) : 100
  const blockers: string[] = []
  if (doneDefs.length < defs.length) blockers.push(`${defs.length - doneDefs.length} deliverable(s) not accepted`)
  if (!estimateOk) blockers.push(`Approved estimate must reach Class ${gate?.requiredEstimateClass}${est ? ` (now Class ${est.cls})` : ' (none approved)'}`)
  if (highRisks) blockers.push(`${highRisks} high risk(s) without a response plan`)
  const info = s.settings.infoFields ? missingInfo(s, p) : []
  if (info.length) blockers.push(`${info.length} required project information field(s) empty`)
  return {
    pct, total: defs.length, done: doneDefs.length,
    missing: defs.filter((x) => !doneDefs.includes(x)),
    estimateRequired: gate?.requiredEstimateClass, estimateClass: est?.cls, estimateOk, highRisks,
    ready: blockers.length === 0, blockers, missingInfo: info.map((f) => f.label),
  }
}

/** Permissions unlocked by gates already passed (SG-07). */
export function permissions(s: AppState, p: Project): Set<StagePermission> {
  const t = templateFor(s, p)
  const out = new Set<StagePermission>()
  for (const st of t.stages.slice(0, p.stageIndex)) st.gate.unlocks.forEach((u) => out.add(u))
  // approved early-start waivers
  for (const w of s.workflows.filter((w) => w.projectId === p.id && w.recordType === 'waiver' && w.status === 'approved')) {
    const perm = w.data.permission as StagePermission | undefined
    if (perm) out.add(perm)
  }
  return out
}

/** Construction NTP also needs an approved safety plan and issued permits (SG-07 + SF). */
export function ntpBlockers(s: AppState, p: Project): string[] {
  const out: string[] = []
  if (!permissions(s, p).has('construction-ntp')) out.push('Authorization gate not passed')
  if (!s.safetyPlans.some((x) => x.projectId === p.id && x.status === 'approved')) out.push('No approved job-specific safety plan')
  const open = s.permits.filter((x) => x.projectId === p.id && x.status !== 'issued')
  if (open.length) out.push(`${open.length} permit(s) not issued`)
  return out
}

/**
 * Record a gate decision (SG-06, SG-09). On Go: converts the approved estimate into the gate's
 * budget, creates Original/Current baselines at the control-budget gate, snapshots, and advances.
 */
export function decideGate(
  d: AppState,
  pid: string,
  outcome: GateOutcome,
  deciderIds: string[],
  notes: string,
  conditions: { title: string; ownerId: string; due: string }[] = [],
) {
  const p = d.projects.find((x) => x.id === pid)!
  const t = templateFor(d, p)
  const st = t.stages[p.stageIndex]
  const r = readiness(d, p)
  const est = d.estimates.filter((e) => e.projectId === pid && e.status === 'approved').sort((a, b) => a.version - b.version).pop()
  const dl = d.deliverables.filter((x) => x.projectId === pid && x.stageIndex === p.stageIndex)
  const actionIds = conditions.map((c) => {
    const id = uid('act')
    d.actions.push({ id, projectId: pid, title: c.title, ownerId: c.ownerId, due: c.due, status: 'open', source: 'gate' })
    return id
  })
  const go = outcome === 'go' || outcome === 'go-with-conditions'
  if (go && st.gate.budgetEvent && est) {
    createBudgetFromEstimate(d, est, st.gate.budgetEvent)
    if (st.gate.budgetEvent === 'control') {
      if (!latestOf(d, pid, 'original')) takeSnapshot(d, pid, 'original', 'Original baseline (authorization)')
      takeSnapshot(d, pid, 'current', 'Current baseline (authorization)')
    }
  }
  const snap = takeSnapshot(d, pid, 'gate', `${st.gate.name} — ${outcome}`)
  d.gateDecisions.push({
    id: uid('gd'),
    projectId: pid,
    stageIndex: p.stageIndex,
    gateName: st.gate.name,
    date: d.settings.asOf,
    outcome,
    decidedBy: deciderIds,
    readiness: r.pct,
    deliverableVersions: Object.fromEntries(dl.map((x) => [x.id, x.version])),
    estimateId: est?.id,
    snapshotId: snap.id,
    conditions: actionIds,
    notes,
  })
  const review = d.gateReviews.find((g) => g.projectId === pid && g.stageIndex === p.stageIndex && g.status === 'scheduled')
  if (review) review.status = 'held'
  if (go) {
    if (p.stageIndex < t.stages.length - 1) {
      p.stageIndex += 1
      ensureDeliverables(d, p)
    } else {
      p.status = 'closed'
      p.dates.closed = d.settings.asOf
    }
  } else if (outcome === 'hold') p.status = 'on-hold'
  else if (outcome === 'cancel') p.status = 'cancelled'
  d.audit.push({ id: uid('aud'), at: nowISO(), actorId: d.currentUserId, entity: 'gate', entityId: pid, projectId: pid, action: outcome, summary: `${st.gate.name}: ${outcome}` })
}
